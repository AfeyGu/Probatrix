# 模板开发指南

模板告诉 Probatrix 要填哪些参数、怎么算、计算书展示哪些内容。第一次写模板，从复制软件自带的钢梁示例开始。后面三篇可以按要改的地方选读。

| 篇名 | 适合在什么时候看 | 读完可以做什么 |
|---|---|---|
| [03-模板快速开始](03-模板快速开始.md) | 第一次改模板 | 复制钢梁示例、给模板取名、刷新并重算，核对两组输入的结果。 |
| [04-参数输入界面](04-参数输入界面.md) | 想调整填写参数的地方 | 设置输入框、下拉框、开关、同行并排、条件显隐和批量列。 |
| [05-计算与验算](05-计算与验算.md) | 想把手算过程写进模板 | 读取参数、换算单位、写条件计算及验算，给批量表格补结果列。 |
| [06-计算书排版](06-计算书排版.md) | 想调整预览和导出正文 | 编排标题、表格、推导和插图，把图文 Markdown 排成一份计算书。 |

想用现成模板填参数、跑批量或导出计算书，可以从《使用说明》开始。[01-使用说明](01-使用说明.md)

在软件顶部选「使用文档」，再用表单里的「文档」下拉框按编号阅读。使用 Markdown 阅读器打开手册时，也可以点击上表里的链接切换篇目。

## 放置模板和配套文件

只有计算代码时，把 `.py` 文件放在 `examples/` 顶层。有配图、数据表或独立正文时，把同一个模板用到的文件集中在一个子文件夹里。子文件夹里的 `template.py` 是软件加载的入口。

```text
examples/
├─ gl.py                         单文件模板（入门：钢梁强度验算）
├─ gl_beam.py                    单文件模板（进阶：简支梁验算）
└─ steel_report/                 带资源的模板
   ├─ template.py                入口，供 Probatrix 执行
   ├─ report.md                  Markdown 正文
   └─ images/
      └─ section.png             截面图
```

图片放 `images/`，需要的数据表可以放 `data/`。把资源作为相对路径引用，复制整个文件夹就能一起带走。如果同一文件夹里有配套的 Python 文件，例如 `materials.py`，可以在入口用 `from .materials import ...` 导入。模板生成的图也可以直接嵌入计算书，省去逐次保存图片。[图片引用和图文计算书写法](06-计算书排版.md#4-插入截面简图或计算简图)

## 写好后共享模板

共享时，单文件模板可以直接发 `.py`，带资源的模板发整个文件夹。对需要额外 Python 库的模板，在入口里声明依赖，并在说明中写出库的安装名称。[计算与验算](05-计算与验算.md#6-声明第三方库)

工程按文件名或文件夹名加计算函数名找到模板。例如 `gl.py` 和 `gl/template.py` 中的 `calc` 都对应 `gl.calc`。把已有的 `gl.py` 迁入文件夹时，保持 `gl` 和 `calc` 这两个名字，保留一处入口，再点「刷新模板」，这样已有工程可以继续打开。界面显示名可以通过 `@template(...)` 调整。

修改 `.py` 入口后，软件会用「模板已改」提醒使用者复核和重算。只更新图片或 Markdown 时，可以直接点击「重算」查看新内容。

遇到模板列表不更新、计算出错或参数校验失败，可按界面提示逐项排查。[模板快速开始](03-模板快速开始.md#遇到问题时怎么找)
