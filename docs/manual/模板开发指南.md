# 模板开发指南

模板是一个 `.py` 文件，告诉 Probatrix 要填哪些参数、怎么算、计算书展示哪些内容。第一次写模板，从复制软件自带的钢梁示例开始。后面三篇可以按要改的地方选读。

| 篇名 | 适合在什么时候看 | 读完可以做什么 |
|---|---|---|
| [模板快速开始](模板快速开始.md) | 第一次改模板 | 复制钢梁示例、给模板取名、刷新并重算，核对两组输入的结果。 |
| [参数输入界面](参数输入界面.md) | 想调整填写参数的地方 | 设置输入框、下拉框、开关、同行并排、条件显隐和批量列。 |
| [计算与验算](计算与验算.md) | 想把手算过程写进模板 | 读取参数、换算单位、写条件计算及验算，给批量表格补结果列。 |
| [计算书排版](计算书排版.md) | 想调整预览和导出正文 | 编排标题、条件表、公式分行、条文引用和计算简图。 |

想用现成模板填参数、跑批量或导出计算书，可以从《使用说明》开始。[使用说明](使用说明.md)

在软件里阅读时，顶部模板选「使用文档」，再用表单里的「文档」下拉框按上表篇名切换。用支持 Markdown 的阅读器打开 `docs/manual/` 下的文件时，可点击目录链接并查看操作截图。

## 写好后共享模板

把模板 `.py`、它读取的数据表和其他配套文件一起交给同事。对需要额外 Python 库的模板，在文件里声明依赖，并在随模板发送的说明中写出库的安装名称。[计算与验算](计算与验算.md#6-声明第三方库)

工程按「文件名.函数名」找到模板，例如 `gl.py` 里的 `calc` 对应 `gl.calc`。模板交付后保留这两个名字，已有工程才能找到对应模板。界面里的显示名可以通过 `@template(...)` 调整。程序会比较模板主文件的内容，文件更新时用「模板已改」提醒使用者复核和重算。多人维护同一套模板时，可以用 Git 管理版本。

遇到模板列表不更新、计算出错或参数校验失败，可按界面提示逐项排查。[模板快速开始](模板快速开始.md#遇到问题时怎么找)
