# Probatrix 模板开发指南

> 写给模板作者：会 Python 的结构工程师。一个模板 = 一个 `.py` 文件，放进模板目录即被扫描加载。
> 完整示例见仓库 `examples/gl.py`；工具的设计取舍见 `.agents/notes/2026-09-05-计算书工具设计定稿.md`。

---

## 0. 你会得到什么

写一个模板，你只负责两件事，其余全部由 Probatrix 接管：

| 你写 | Probatrix 自动做 |
|---|---|
| **参数声明**（Pydantic + Field） | 生成参数表单、批量表格的列、工程文件的参数 JSON |
| **计算 + Probatrix 写书** | 实时预览（KaTeX 渲染）、批量重算、比值列、导出 HTML/PDF |

不写一行界面代码，不碰 HTML，不排版。

## 1. 最小模板

```python
# gl.py —— 钢梁强度验算
from pydantic import BaseModel
from probatrix import Probatrix, Field, template


class GLParams(BaseModel):
    steel: str = Field("Q235B", label="钢材牌号",
                       choices=["Q235B", "Q355B"], group="材料")
    fy: float = Field(215, label="抗弯强度设计值", unit="N/mm²", group="材料", gt=0)
    gamma_x: float = Field(1.05, label="截面塑性发展系数", group="截面", ge=1.0, le=1.25)
    Wx: float = Field(1.0e6, label="截面模量", unit="mm³", group="截面", gt=0)
    Mx: float = Field(100, label="弯矩设计值", unit="kN·m", group="荷载")


@template("钢梁强度验算", description="GB 50017-2017 弯曲正应力验算")
def calc(p: GLParams) -> Probatrix:
    b = Probatrix(title="钢梁强度验算")
    sigma = p.Mx * 1e6 / (p.gamma_x * p.Wx)      # kN·m → N·mm

    b.h2("1. 强度验算")
    b.formula(r"\sigma = \dfrac{M_x}{\gamma_x W_x} \le f",
              cite=("GB 50017-2017", "4.1.1"))
    b.subs(rf"\sigma = \dfrac{{{p.Mx:g} \times 10^6}}"
           rf"{{{p.gamma_x:.2f} \times {p.Wx:,.0f}}}"
           rf"= {sigma:.1f}\ \mathrm{{N/mm^2}}")
    b.check("抗弯强度", value=sigma, limit=p.fy, unit="N/mm²",
            expr=r"\sigma \le f", cite=("GB 50017-2017", "4.1.1"))
    return b                                       # 必须返回 Probatrix
```

保存后界面点「刷新模板」即生效，无需重启服务。

## 2. 参数声明

### 2.1 类型 → 界面控件（自动映射）

| 注解类型 | 表单控件 | 批量表格控件 |
|---|---|---|
| `float` / `int` | 数字输入框 | 数字输入框（可被 Excel 粘贴填充） |
| `str` + `choices` | 下拉框 | 下拉框 |
| `str`（无 choices） | 文本框 | 文本框 |
| `bool` | 开关 | 开关 |
| 其他（`list`、`dict`…） | 文本框（JSON 串） | 同左——**MVP 不建议用** |

### 2.2 Field 参数

```python
Field(默认值,
      label="中文名",          # 界面显示；缺省显示字段名
      unit="N/mm²",            # 单位，仅展示用（见 §6 单位纪律）
      choices=["Q235B", ...],  # 下拉选项
      group="材料",            # 分组：表单折叠分组；批量模式下成为「统一设置」的颗粒
      row="dims",               # 布局：声明相邻且同标记的参数在表单并排一行
      show_if="steel == 'Q235B'",  # 条件显隐：表达式不满足时表单隐藏该参数（值保留）
      ge=0, gt=0, le=1.25,     # 透传 pydantic 校验，非法值会在界面标红并显示原因
      description="补充说明",   # 透传 pydantic
      )
```

### 2.3 group 与批量模式

- `group` 相同的参数（如「材料」组）在批量视图顶部可整组「统一设置」：改一处 → 应用到全部行；
- 每行不同取值的参数（如弯矩、截面）单独一组或用默认组；
- 批量表格的**列显隐**由使用者配置，模板作者不用管；想默认不占列的次要参数
  （如分项系数、容重）在 Field 里加 `batch_hidden=True`，使用者在「列显隐」里可勾回。

### 2.4 布局原语：row 并排与 show_if 条件显隐

参数一多，单列堆叠会又长又空；结构模板还常有「选了 A 才需要填 B」的分支。两个原语解决：

- **`row="标记"`**——声明顺序上**相邻**且同标记的参数在单件表单并排一行（如踏步宽 a 与踏步高 d）。
  不相邻的同标记参数分属两行；不给 `row` 的参数独占一行。批量表格侧无效果（表格就是列）。
- **`show_if="表达式"`**——不满足时单件表单隐藏该参数，**值保留**（切回条件后输入不丢）。
  表达式两种形式：`参数名 == '字面值'`（`!=` 同理，字符串建议带引号，数字裸写）、
  或直接引用 bool 参数名（如 `show_if="finish"`）。批量表格侧降级为默认隐藏列（「列显隐」可勾回）。

**关键语义**：`show_if` 只是界面提示，不改变计算输入——开关想让计算也跟着变
（如「无面层 → 面层荷载计 0」），模板计算函数里要自己分支（见 `examples/stair.py`
的 `finish / plaster` 开关写法），并让计算书的公式行与条件表同步注明。

### 2.5 校验失败会怎样

界面该输入框标红，预览区显示「参数校验失败 + 原因」——不会静默算错。所以**把限值写进声明**（`gt=0`、`le=1.25`）是免费的正确性保险。

## 3. Probatrix API

链式调用：每个方法返回 `self`。渲染目标：**HTML**（`$$…$$` 独立公式与 `$…$` 行内公式交给前端 KaTeX；另可导出 Markdown 纯文本，仅为阅读用、不参与渲染）。

| 方法 | 用途 | 渲染效果 |
|---|---|---|
| `h1/h2/h3(text)` | 标题（编号自己写，如 `"1. 强度验算"`） | 一/二/三级标题 |
| `p(text)` | 文字段落，支持行内 `$…$` 与 `**粗体**` | 段落（文本含换行时逐行成段） |
| `derive(left, *steps, cite=None)` | **推导链**（代入过程推荐写法，见下） | 等式串：首行 `left = 段1`，其后 `= 段2`、`= 段3` 对齐连排 |
| `formula(latex, cite=None)` | **符号公式**（独立公式块） | 居中公式块 + 依据标注行 |
| `subs(latex, cite=None)` | **代入数值**（跟在 formula 后） | 独立公式块 |
| `check(…)` | 验算项（见 §4） | 判定行（圆点）+ 自动汇总表 |
| `table(header, rows)` | 自由表格 | 表格（单元格支持 `**粗体**`） |
| `image_bytes(data, mime, caption, side=None)` | 内嵌图片（**推荐**，见 §5） | 居中图片 + 居中图名（小字）；`side="right"/"left"` 图文环绕 |
| `image(path, caption, side=None)` | URL 图片（导出离线文件时相对路径会裂图，慎用） | 同上 |
| `metric(name, value)` | 批量表格附加指标（不进正文，见 §4 末） | 无（仅进批量结果列） |

### 3.1 内容语法契约

**结构只由 API 决定**：`p()` 永远是段落——文本写得再像 Markdown（`##`、`>`、`-` 开头）也按字面显示，不会被误解析成标题/引用/列表。转义自动完成（`<`、`>`、`&`、引号），无需操心。

文本字段（标题 / 段落 / 表格单元格 / 图名）支持的**全部**行内语法只有两条：

| 语法 | 效果 | 示例 |
|---|---|---|
| `**…**` | 粗体 | `**满足**` → **满足** |
| `$…$` | 行内公式（KaTeX） | `$f=305$ N/mm²` |

**不支持**（一律按字面显示）：链接、图片语法、HTML 标签、斜体单星 `*`、有序列表、嵌套结构。已知限制：无法字面输出成对的 `**` 与 `$…$`（没有转义机制）；`$…$` 出现在任何文本里都会被 KaTeX 渲染为公式。

契约由 `tests/test_html_contract.py` 锁定——改实现必须同步本节，反之亦然。

`cite=("GB 50017-2017", "4.1.1")` 渲染为公式下方的引用块「依据：GB 50017-2017 第 4.1.1 条」。

**书写惯例**（结构计算书的标准姿势，界面预览按此渲染）：

```python
b.derive(r"\sigma",                                       # ①+② 推导链（推荐）
         r"\dfrac{M_x}{\gamma_x W_x} \le f",
         rf"\dfrac{{{v}}}{{…}} = {sigma:.1f}\ \mathrm{{N/mm^2}}")
b.check("抗弯强度", value=sigma, limit=p.fy, …)           # ③ 判定
```

推导链渲染为等式串（`aligned` 对齐）。旧写法 `formula()` + `subs()`
（两个独立公式块）仍完全支持。

#### 推导链排版规则（换行审美——写模板时按此决定分段）

**三种布局，优先级从高到低**（能不挤就用前面的）：

| 布局 | 形态 | 判据 |
|---|---|---|
| ① 单行 | `A = 公式 = 代入 = 值` | 全串源字符（left+各段）合计 **≤120**：只给一段，段内用 ` = ` 连 |
| ② 两行 | `A = 公式` ↵ `= 代入 = 值` | 全串 >120：分两段（段1=符号公式右侧，段2=代入起连排） |
| ③ 逐行 | `A = 公式` ↵ `= 代入` ↵ `= 值` | 两行的行2（=代入=值）仍 >120：拆三段 |

硬规则：

- **截断点只允许在「符号公式 → 数值代入」的边界**。禁止行1 拖着代入、
  行2 只剩值的切法（`A = 公式 = 代入` ↵ `= 值` ✗）；
- 120 是源字符粗估（left 与各段 `len()` 之和），目测一行放不下就升一级；
- **不同左符号 = 不同推导链**，各自调 `derive`，绝不塞进同一条链
  （如 `L = a·n` 与 `L_n = L+L₁+L₂` 是两条）；
- **说明性括号**（如 (底面抹灰)、(\text{限 } [0.2, 1])）写在**最后一段的行尾**，
  不夹在公式中间；
- **取值行**（计算值须落在范围内、否则取定值）：用 `take=` 参数，渲染为
  行首带「取」字的独立行「取 A = max(计算值, 限值) = 最终值」：
  `b.derive(r"A_s", rf"…= 68.2\ \mathrm{mm^2}", take=rf"\max(68.2,\ 200) = 200.0\ \mathrm{mm^2}")`；
- 依据 `cite=` 挂在 `derive` 参数上，渲染在整条链下方。

计算深度不设限：想写多细写多细（`p()` 补文字说明、`table()` 列中间量），但每个模板自己保持风格一致。

## 4. check 与结论

```python
b.check(name="抗弯强度",
        value=sigma, limit=p.fy,        # 数值 vs 限值
        op="le",                        # "le"=value≤limit 为满足（默认）；"ge"=value≥limit
        expr=r"\sigma \le f",           # 可选：符号表达式，显示在判定行
        unit="N/mm²",                   # 展示单位
        cite=("GB 50017-2017", "4.1.1"),
        ratio=None)                     # 比值；缺省 le=value/limit、ge=limit/value；分母为 0 时置 None（显示「—」）
```

`check()` 自动完成三件事：

1. 正文判定行：`抗弯强度：σ≤f：95.24 ≤ 215 N/mm²，比值 0.443 —— **满足**`（不满足加粗）；
2. 计算书末尾自动汇总「验算结论」表（验算项/数值/比值/结论；有 check 带 `cite` 时才附「依据」列）；
3. 批量表格每行显示**最大比值**（`max_ratio`，超限红色）——这是使用者筛选危险构件的依据，所以**每个模板都应至少有一个 check**。

代码里也可读：`b.checks`、`b.max_ratio`、`b.all_ok`。

**批量结果列（`metric()`）**：`b.metric("A端支座配筋", "Φ8@200")` 声明结果指标，
不进正文，随 `RunResult.metrics` 送到前端；批量视图为出现过的指标名动态增加
结果列（按首次出现顺序，全行共用一列）。适合输出选筋结果、关键截面内力等
使用者要扫一眼对比的量。

## 5. 插图：matplotlib 截面简图

用 `image_bytes()` 内嵌（base64 data URI），预览、导出、离线全可用：

```python
import io
import matplotlib
matplotlib.use("Agg")                       # 服务端无界面
import matplotlib.pyplot as plt

matplotlib.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]
matplotlib.rcParams["axes.unicode_minus"] = False   # 负号显示


def section_fig(p: GLParams) -> bytes:
    fig, ax = plt.subplots(figsize=(3, 4))
    # ... 按参数画截面 / 计算简图 ...
    buf = io.BytesIO()
    fig.savefig(buf, format="png", dpi=150, bbox_inches="tight")
    plt.close(fig)
    return buf.getvalue()


b.image_bytes(section_fig(p), caption="截面简图")
```

**图文环绕**（`side="right"` / `"left"`）：图片浮动到一侧（约占 45% 宽），
其后的**文字段落**贴边环绕；公式、表格、标题、判定行自动收边回全宽，
不受环绕影响——适合「简图挂右 + 两三行说明挂左」的排版（仿 Word 四周型环绕）：

```python
b.p("采用焊接 H 形截面，翼缘 200×12，腹板 400×8……")
b.image_bytes(section_fig(p), caption="截面简图", side="right")
b.p("这段文字贴着图左侧环绕……")
b.formula(r"\sigma = …")     # 公式自动回到全宽
```

> ⚠️ **用了 matplotlib（或任何第三方库）的模板，必须在文件顶部声明依赖**
> （模块级，import 名）：
>
> ```python
> __probatrix_requires__ = ["matplotlib"]
> ```
>
> `__probatrix_requires__` 填导入名，供界面提前提示缺少的库。模板说明应列出对应的 PyPI 包名。
> 便携版用户可关闭 Probatrix，在解压目录执行 `.\python\python.exe -m pip install 包名`，然后重新打开计算。
> 只使用标准库和 Probatrix 基础依赖的模板可省略此声明。

## 6. 单位纪律（强制约定）

- 模板内部**统一 SI 基本单位**：N、mm、MPa、kN·m → N·mm 等换算**写在算式处**（如 `p.Mx * 1e6`）；
- `Field(unit=...)` 只负责界面展示，**不参与换算**；
- 不做自动单位引擎——单位错误靠「声明里的 unit 标注 + 算式处显式换算」双保险。

## 7. 数字进公式的格式

公式里直接拼数字容易出丑，推荐：

```python
rf"\sigma = \dfrac{{{p.Mx:g} \times 10^6}}{{…}}"     # :g 避免 100000000.0
rf"{{{p.Wx:,.0f}}}"                                   # 千分位只在表格/文字里用
rf"{sigma:.1f}\ \mathrm{{N/mm^2}}"                    # 单位用 \mathrm{}，别用文字
```

- f-string 里 LaTeX 的 `{}` 要写成 `{{}}`，建议统一用 `rf""` 前缀；
- LaTeX 公式内**不要放千分位逗号**（会被当成间距），用 `\times 10^{n}`；
- `.4g` 左右的有效位数适合展示（Probatrix 结论表默认就是这个量级）。

## 8. 共享数据模块与复杂计算

- 同目录的普通 `.py` 直接 `import`：`Hsteel.py` 放国标截面表，`gl.py` 里 `import Hsteel`；
- 目录就是一个 git 仓库——数据表、模板都能版本管理、同事拉取即得；
- 计算随便写：循环试算、迭代收敛都行。**计算量大的模板加 `manual=True`**，界面就不自动实时算，改用「全部重算」按钮：

```python
@template("整体稳定验算（迭代）", description="…", manual=True)
def calc(p: P) -> Probatrix: ...
```

**可选的 `name` 形参**：模板函数声明 `def calc(p: P, *, name: str = "")` 时，
计算项的「名称」（批量首列/单项标题）会传入，用作计算书里的项目编号，
不用再重复声明编号参数：

```python
@template("板式楼梯计算")
def calc(p: P, *, name: str = "") -> Probatrix:
    b = Probatrix(title=f"楼梯计算书 · {name or '未命名'}")
    ...
```

## 9. 调试与发布

| 场景 | 行为 |
|---|---|
| 改了模板代码 | 界面点「刷新模板」，立即生效，**不用重启服务** |
| 计算抛异常 | 预览区原样显示 **Python traceback**——这就是你的调试界面 |
| 参数非法 | 该行标红 + 校验原因 |
| 忘了 `return b` | 明确报「模板返回值类型错误」，指出实际返回的类型 |
| 模板文件写坏（语法错） | 只这一个文件报错，其他模板不受影响 |
| 改动已保存工程的模板 | 使用者界面出现「模板已改」标记，提示旧结果可能过期 |

**命名与版本建议**：

- 文件名即模板 id 的一部分（`gl.py` → `gl.calc`），**发布后不要改文件名**——工程文件按 id 引用，改名会让旧工程找不到模板；
- 用 git 管模板目录；改动后旧工程的「模板已改」提示是按文件 sha256 比对的；
- 一个模板只做一类验算（宁多勿杂），参数控制在十几项以内。

## 10. 契约速查

```python
# ---------- 导入 ----------
from probatrix import Probatrix, Field, template

# ---------- 声明 ----------
__probatrix_requires__ = ["matplotlib"]   # 可选：第三方库（import 名），缺了运行前提示

# ---------- 声明 ----------
@template(name: str, description: str = "", manual: bool = False)
def calc(p: <PydanticModel>) -> Probatrix: ...   # 或 (p, *, name: str = "")：名称作项目编号传入

Field(default, label=, unit=, choices=, group=, batch_hidden=True, row=, show_if=, **pydantic 参数如 gt/ge/le)

# ---------- Probatrix 方法 ----------
h1/h2/h3(text) · p(text)
formula(latex, cite=None) · subs(latex, cite=None)
check(name, value, limit, op="le"|"ge", expr=None, unit=None, cite=None, ratio=None)  # 比值分母为 0 时自动置 None
table(header: list[str], rows: list[list])
image_bytes(data: bytes, mime="image/png", caption="") · image(path, caption="")
metric(name: str, value)                        # 批量表格附加指标列
# 属性：b.checks / b.max_ratio / b.all_ok
```
