# 计算与验算

在模板的 `calc` 函数里，先从 `p` 取本次输入，做单位换算和计算，再把结果交给 `b.check()`。例如在钢梁练习里，弯矩和截面参数决定应力，抗弯强度设计值给出应力上限。以下片段按任务插入或替换 `gl_practice.py` 的相应位置，函数里的代码保留四个空格缩进。[模板快速开始](03-模板快速开始.md)

## 1. 把一条手算式写成 Python

找到 `calc` 里计算 `sigma` 的这一行。`p.Mx` 是表单里的弯矩，`p.gamma_x` 是塑性发展系数，`p.Wx` 是截面模量。`=` 把右侧算出的数存到左侧的 `sigma`，`*` 表示乘，`/` 表示除，括号把两个分母因子乘在一起。

```python
    sigma = p.Mx * 1e6 / (p.gamma_x * p.Wx)
```

这里 `1e6` 是一百万。弯矩输入单位为 `kN·m`，乘一百万后成为 `N·mm`。除以截面模量的 `mm³`，得到 `N/mm²`。默认值代入是 `100 × 1000000 ÷ (1.05 × 1000000)`，应力约为 `95.24 N/mm²`。

写自己的模板时，先选定相互匹配的公制单位，例如钢梁应力计算配套使用 N、mm 和 N/mm²。把换算写在算式附近。输入毫米、荷载公式要求米时，用 `p.t1 / 1000` 将厚度换为米。`Field(unit=...)` 给输入人提示该填什么单位，代码里的乘除决定实际换算。

## 2. 把数值和限值交给验算

在钢梁练习中找到 `b.check(...)`。下面把每个参数单独写一行，便于看清哪一个是计算结果、哪一个是限值。写正式计算书时，按项目采用的规范填写 `cite` 条文标注。

```python
    b.check(
        "抗弯强度",
        value=sigma,
        limit=p.fy,
        op="le",
        expr=r"\sigma \le f",
        unit="N/mm²",
    )
```

`value` 是拿去比较的数，`limit` 是界限。下面两种写法比较的方向相反，比值都按示例中的正数取值计算。

| 工程判断 | `op` 写法 | 满足条件 | 默认比值 |
|---|---|---|---|
| 应力不得超过强度设计值 | `"le"`，省略时也用这一项 | `value ≤ limit` | `value / limit` |
| 实配面积至少达到计算所需面积 | `"ge"` | `value ≥ limit` | `limit / value` |

例如实配面积为 `314 mm²`、所需面积为 `280 mm²`，可以写 `b.check("实配钢筋面积", value=314, limit=280, op="ge", unit="mm²")`。结论为「满足」，比值约为 `0.892`。分母为零时比值显示为「—」，仍按 `op` 比较原数值。提供 `ratio=数值` 时报告采用给出的比值，结论仍由 `value`、`limit` 和 `op` 决定。

`expr` 是正文上显示的符号式，`unit` 和 `cite` 分别给出比较数值的单位和条文依据。验算比较使用原数值，右侧显示时会按位数格式化。[计算书排版](06-计算书排版.md)

## 3. 读结论和添加批量结果列

每次 `b.check()` 会输出一条正文判定。只要有验算项，文末就会自动生成汇总表。至少一项验算带 `cite` 时，表中会多一列「依据」。批量表格对每个计算项显示其所有有效比值中的最大值和验算结论。需要给出工程判定的模板，应为要比较的数值逐项写 `check`。代码里也可以读 `b.checks`（各项验算）、`b.max_ratio`（最大比值）和 `b.all_ok`（有验算项且全部满足）。

使用者要在批量表格里扫看某个计算量，可以在钢梁练习的 `return b` 之前加一行。保存、刷新并在批量视图点「全部重算」，可以看到「计算应力」结果列。每行各填自己的结果，同名指标用同一列。`metric` 负责批量结果列，计算书中展示该值可以继续用公式、文字或表格。

```python
    b.metric("计算应力", f"{sigma:.2f} N/mm²")
```

`f"..."` 可以把花括号里的值放入文字。`:.2f` 表示保留两位小数，只改这一处的显示格式。

## 4. 让开关参与计算

楼梯模板用 `finish` 表示是否有面层。《参数输入界面》中的 `show_if` 控制厚度和容重的输入框。要让面层荷载跟开关变化，计算函数从 `p.finish` 取开关值。下面把示例里的一行条件算式展开成两段，方便看清开关的两个取值。

```python
    if p.finish:
        g3 = (p.a + p.d) / p.a * (p.t1 / 1000) * p.r1
    else:
        g3 = 0.0
```

开时用踏步宽高、面层厚度和容重算 `g3`，关时取 `0.0`。在内置「板式楼梯计算」里切换「楼梯面层」，可以在计算书的条件表和面层荷载计算处核对两种结果。正文也可以用同一个 `if` 条件写出有面层和无面层的说明。[参数输入界面](04-参数输入界面.md#4-按开关或选项显示参数) · [楼梯示例 `stair.py`](../../examples/stair.py)

## 5. 查表、迭代和使用计算项名称

- **查材料或截面表**。把表整理为由牌号或型号索引的数据，例如楼梯模板用 `CONCRETE[p.concrete]` 取混凝土参数。多人共用的表可以放进模板目录里的普通 `.py` 文件，例如 `Hsteel.py`，模板写 `import Hsteel` 并按该文件定义取值。分享时把表和模板放在一起。[楼梯示例 `stair.py`](../../examples/stair.py)
- **耗时计算**。循环试算、迭代或查表都可以写进 `calc`。耗时较长时，在 `@template(...)` 括号内加 `manual=True`。输入改好后，在单项点「重算」，在批量点「全部重算」。
- **在计算书里显示项目编号**。将钢梁练习的函数首行改为 `def calc(p: GLParams, *, name: str = "") -> Probatrix:`，软件会把当前计算项的「名称」传给 `name`。函数内可用 `b = Probatrix(title=f"钢梁练习计算书 · {name or '未命名'}")` 作标题。修改计算项名称后点「重算」即可核对。

## 6. 声明第三方库

用到 matplotlib 等额外安装的 Python 库时，在文件顶层写出依赖导入名。用到这些库的 `import` 可放在相应的计算或绘图函数内，让软件先加载模板、读取声明并在运行前提示缺库。

```python
__probatrix_requires__ = ["matplotlib"]
```

共享模板时，记录依赖的 PyPI 包名，也就是安装命令里使用的名称。它可能与代码里的导入名不同。依赖安装方式见《使用说明》。[使用说明](01-使用说明.md#安装与启动)
