# 使用说明

面向使用者：装好软件、选模板、填参数、出计算书。要写新模板请看 [模板开发指南.md](模板开发指南.md)。

## 安装与启动

### Windows 便携版（推荐）

在装有 **Microsoft Edge WebView2 Runtime** 的 Windows 10/11 x64 上，完整解压 `probatrix-<版本>-windows-x64-portable.zip`，双击 `Probatrix.exe`。移动时带上整个文件夹。

包内附 Python 3.12、常用计算库、示例模板和使用说明，内置示例可离线计算。

自定义模板和配套数据文件放在 `examples/`。若模板提示缺库，退出 Probatrix，在解压目录用包内 Python 安装（把「包名」换成模板说明里的 PyPI 包名）：

```powershell
.\python\python.exe -m pip install 包名
```

日志位于 `%LOCALAPPDATA%\io.github.afeygu.probatrix\logs\probatrix-desktop.log`，WebView2 缓存也保存在本机应用数据目录。

### 浏览器版

```bash
git clone https://github.com/AfeyGu/Probatrix.git
cd Probatrix
python -m pip install .
probatrix serve --templates examples
```

默认地址 `http://127.0.0.1:8317`，端口被占用时自动递加。省略 `--templates` 时使用 `~/Probatrix模板/`，也可以指定自己的模板目录：

```bash
probatrix serve --templates "D:/我的模板" --port 8317
```

## 界面

左侧选择计算项，中间输入参数，右侧实时预览计算书。批量表格支持从 Excel 粘贴。

桌面窗口使用自绘标题栏：顶栏空白处可拖动，双击可最大化或还原；普通窗口可沿四边及右下圆弧内侧缩放。顶栏可切换雾蓝、素白和暖砂三套浅色主题。

## 工作流程

1. 选模板 → 界面按模板声明自动生成参数表单
2. **单项**：左侧改参数，右侧实时预览计算书（防抖 300ms，与导出排版一致，所见即所得）
3. **批量**：表格一行一根构件；支持从 Excel 直接 Ctrl+V 粘贴；每行显示比值与结论；
   行可复制 / 删除 / 上移 / 下移，列宽可拖动（有单行显示下限），列多时横向滚动、名称列固定；
   顶部「统一设置」可把某组参数应用到全部行——各行取值不同的参数会标「＊」，
   留空则保持各行原值，填值则统一该列
4. 保存工程（`.pbproj`，纯 JSON：参数 + 模板 id + hash）→ 下次打开即复现
5. 导出 HTML（单计算项，或整个工程分页合并）→ 浏览器 Ctrl+P 存 PDF

## 导出

- 默认导出走 KaTeX CDN：文件极小，但需联网才能渲染公式；
- 顶栏「⋯」菜单勾选「导出离线版」则内联样式与 woff2 字体（约 0.65 MB），断网或内网可直接打开。该偏好记在本地。

## 模板改动后会怎样

模板代码改过（hash 变化），界面会提示「模板已改」，提醒旧结果可能失效。在模板目录更新文件后点「刷新模板」即可加载新版本，不必重启服务。
