# 参数输入界面

这里的界面是使用模板时填写参数的单项表单和批量表格。修改模板文件里 `class GLParams(BaseModel):` 下的 `Field(...)`，就能调输入框的标题、类型和布局。下面先用 `gl_practice.py` 练习，再看内置的「板式楼梯计算」怎样让输入框并排和按条件出现。[模板快速开始](03-模板快速开始.md)

每次改完 `.py` 文件，保存后点「刷新模板」。要验证新加的参数或新的默认值，点「＋ 加一项」用默认值创建一项。已有计算项会继续使用工程里保存过的输入。

## 1. 读懂一个输入框

在钢梁练习的 `GLParams` 里找到 `Mx`。它的定义是下面这几行，整段都缩进在 `class` 里面。

```python
    Mx: float = Field(
        100, label="弯矩设计值", unit="kN·m", group="荷载",
    )
```

| 写法 | 在软件里有什么作用 |
|---|---|
| `Mx` | 参数在代码里的名字，计算用 `p.Mx` 取值。 |
| `float` | 用数字输入框，允许小数。 |
| `100` | 新计算项的初始输入。 |
| `label="弯矩设计值"` | 表单输入框和批量表头显示的名称。省略时显示 `Mx`。 |
| `unit="kN·m"` | 输入框和表头旁的单位提示。填写 `100` 时，计算函数读到的就是 `100`，单位换算写在算式里。 |
| `group="荷载"` | 单项表单把它放到「荷载」组。 |

试着把 `label` 改成 `"梁端弯矩设计值"`，保存并刷新。选「钢梁练习」，展开「荷载」，可以看到新标签。公式仍通过 `p.Mx` 取值。

## 2. 选择控件和默认值

| 用户要填写什么 | 参数写法 | 单项表单中显示 |
|---|---|---|
| 长度、弯矩等可带小数的量 | `float` | 数字输入框 |
| 根数、踏步数等整数 | `int` | 数字输入框 |
| 项目说明等自由文本 | `str` | 文本框 |
| 从几种牌号里选择 | `str` 配合 `choices=[...]` | 下拉框 |
| 要或不要某项做法 | `bool`，默认填 `True` 或 `False` | 开关 |

例如钢梁模板给「钢材牌号」设置了两个选项。`"Q235B"` 是初始值，`choices` 方括号里的每一项都会出现在下拉框中。钢梁示例把强度设计值 `fy` 作为另一个独立输入。要按牌号确定强度，可以在计算函数里写查表逻辑。[计算与验算](05-计算与验算.md)

```python
    steel: str = Field(
        "Q235B", label="钢材牌号", choices=["Q235B", "Q355B"], group="材料",
    )
```

下拉框的选项负责引导选择。计算需要约束输入时，在参数类型和取值范围里声明校验规则。`list`、`dict` 等复杂值会以普通文本框编辑，入门时优先用上表中的类型。

## 3. 用分组和同行标记安排位置

`group` 相同的参数会收在一个可展开的分组里，省略时归入「参数」组。在同一组内，把需要并排的参数写相邻，再给它们填相同的 `row`。`row` 的文字是代码里的标记，可以取一个好认的名字。每个单独出现的参数占一行。

在钢梁练习的 `GLParams` 里，找到前后相邻的 `gamma_x` 和 `Wx`，把两段一起换成下面这段。刷新后打开「截面」组，塑性发展系数和截面模量会排在同一行。

```python
    gamma_x: float = Field(
        1.05, label="截面塑性发展系数", group="截面", ge=1.0, le=1.25,
        row="section",
    )
    Wx: float = Field(
        1.0e6, label="截面模量", unit="mm³", group="截面", gt=0,
        row="section",
    )
```

同样，在「板式楼梯计算」的「几何」组，踏步宽度和踏步高度相邻且都写了 `row="step"`，因此并排。并排取决于同组内可见参数的顺序，中间插入另一个独占一行的参数会把它们分开。批量视图里，每个参数各占一列。[楼梯示例 `stair.py`](../../examples/stair.py)

## 4. 按开关或选项显示参数

在楼梯的「荷载与系数」组，`finish` 是「楼梯面层」开关。`t1` 和 `r1` 都写了 `show_if="finish"`，因此开关打开时会看到厚度与容重。关闭时输入框隐藏，原来的输入值保留，重新打开时会显示出来。

```python
    finish: bool = Field(True, label="楼梯面层", group="荷载与系数", row="finish")
    t1: float = Field(30, label="面层厚度 t1", unit="mm", ge=0,
                      group="荷载与系数", row="finish", show_if="finish")
    r1: float = Field(22, label="面层容重 r1", unit="kN/m³", gt=0,
                      group="荷载与系数", row="finish", show_if="finish")
```

可以在单项里把面层厚度改成 `35 mm`，关闭后再打开「楼梯面层」，确认厚度回到了 `35 mm`。`show_if` 负责表单显隐，计不计面层荷载由计算函数按 `p.finish` 决定。[计算与验算](05-计算与验算.md#4-让开关参与计算)

也可以对下拉值使用 `show_if="steel == 'Q235B'"`，或用 `!=` 表示值不相等。字符串值放在引号里，数值可以直接写，例如 `show_if="n == 5"`。表达式里的名字使用 `steel`、`finish` 这样的参数名。

## 5. 设置批量表格默认显示哪些列

给不必逐行填写的参数加 `batch_hidden=True`，例如楼梯模板里的恒载分项系数。带 `show_if` 的参数同样默认隐藏。批量视图的「列显隐」可以将这些列勾回，工程里保存过的列设置优先生效。

批量的「统一设置」按声明顺序列出全部参数，包括默认隐藏的列。可以在里面选定共用的参数值，再点「应用到全部」。每行各自保存实际输入值。[使用说明](01-使用说明.md#工作流程)

## 6. 写出取值要求

| 规则 | 意思 | 示例 |
|---|---|---|
| `gt` / `ge` | 大于 / 大于等于 | 截面模量 `gt=0`，踏步数 `ge=1` |
| `lt` / `le` | 小于 / 小于等于 | 塑性发展系数 `le=1.25` |

这些规则由 Pydantic 检查，也就是 `BaseModel` 所用的 Python 参数校验库。还可以填写 `description="补充说明"` 记录参数含义。试着把钢梁练习的截面模量 `Wx` 输入为 `0`，右侧会显示「参数校验失败」及对应的参数名和原因。改回 `1000000` 后再检查计算结果。
