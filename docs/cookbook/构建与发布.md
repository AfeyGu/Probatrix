# 构建与发布

前置：前端有改动时先 `cd web && npm run build`。打包配置在 `pyproject.toml`（package-data 含 web/vendor）与 `MANIFEST.in`，两者要同步维护。

## 校验 wheel

```bash
pip wheel --no-deps -w _wheelcheck .
```

wheel 应约 2.4 MB，含 `src/probatrix/web` 与 `src/probatrix/vendor`。用完删掉 `_wheelcheck/`。

## Windows x64 便携包

构建机需要：Python 3.11+、Rust 的 `x86_64-pc-windows-msvc` 工具链、Visual Studio C++ Build Tools、`pip install build`。

```powershell
python tools/build_release.py
```

产出 `release/probatrix-<版本>-windows-x64-portable.zip`。脚本用 `Cargo.lock` 构建 Tauri Release，下载 Python 3.12 嵌入版，把 Probatrix 和常用计算库装进包内 `python/`，首次构建需要联网。包内布局：

```
Probatrix.exe
使用说明.txt          ← 脚本生成，纯文本，解压后第一眼看的极简入门
python/               ← 嵌入版 Python + Probatrix + numpy/scipy/pandas/matplotlib/openpyxl
examples/             ← 单文件模板及带资源的模板子目录
docs/manual/          ← 编号用户手册和 images/ 配图
```

目标机需已装 Microsoft Edge WebView2 Runtime。日志与 WebView2 缓存位于本机应用数据目录（`%LOCALAPPDATA%\io.github.afeygu.probatrix\`）。

## 桌面宿主调试

```powershell
py -3.12 -m pip install -e .
cargo build --release --locked --manifest-path src-tauri/Cargo.toml
$env:PROBATRIX_PYTHON = py -3.12 -c 'import sys; print(sys.executable)'
$env:PROBATRIX_TEMPLATES = (Resolve-Path .\examples).Path
.\src-tauri\target\release\Probatrix.exe
```

`PROBATRIX_PYTHON` 指向装了 Probatrix 与模板依赖的开发解释器。每次启动使用新的本机端口。

宿主自动化测试：

```bash
cargo test --locked --manifest-path src-tauri/Cargo.toml
```

Windows 上可用 `PROBATRIX_TEST_PYTHON` 指向实际解释器。宿主设计细节见 [.agents/notes/2026-11-21-tauri-desktop.md](../../.agents/notes/2026-11-21-tauri-desktop.md)。
