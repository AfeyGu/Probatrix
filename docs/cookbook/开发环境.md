# 开发环境

## 依赖

- Python 3.11+（便携包内置 3.12）
- Node 仅在改前端时需要

## 后端

```bash
pip install -e .                                  # 可编辑安装，改后端即时生效
python -m pytest tests -q                         # 全量：契约 / 后端 / API / 桌面后台 / 工程文件 / 模板回归
python -m pytest tests/test_server.py::test_run_batch -q   # 单个测试

probatrix serve --templates examples --port 8317 --no-browser   # 调试用，不自动开浏览器
probatrix serve --templates <目录>                  # 生产形态：自动开浏览器，默认端口 8317
```

省略 `--templates` 时模板目录取 `~/Probatrix模板/`。

**重启边界**：服务端 Python 代码改动需重启服务；模板 `.py` 改动点界面「刷新模板」即可生效，不必重启。

## 前端

```bash
cd web
npm install
npm run dev      # vite:5173，/api 代理到 127.0.0.1:8317
npm run build    # 构建到 src/probatrix/web/，并拷贝 vendor-katex
```

前端改动后**必须** `npm run build` 再提交——`src/probatrix/web` 是提交入库的构建产物，pip 使用侧不装 Node。

## 本地服务排错

按端口找 PID 再杀，不要按进程名杀（会连带杀掉其他 Python）：

```bash
netstat -ano | findstr :8317
taskkill /F /PID <pid>
```
