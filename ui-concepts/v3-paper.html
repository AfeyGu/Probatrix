三、梯段板荷载计算

荷载均按水平投影面每平方米计。梯段板倾斜角：

$$\alpha = \arctan \dfrac{d}{a} = \arctan \dfrac{150}{280} = 0.4918\ \mathrm{rad}\quad(\cos\alpha = 0.8815)$$
(3-1)
$$g_{k1} = \dfrac{r \cdot d}{2} = \dfrac{25 \times 150}{2 \times 1000} = 1.875\ \mathrm{kN/m^2}$$
(3-2)
$$g_{k2} = \dfrac{t \cdot r}{1000\cos\alpha} = \dfrac{100 \times 25}{1000 \times 0.8815} = 2.836\ \mathrm{kN/m^2}$$
(3-3)
$$g_k = 1.875 + 2.836 + 1.014 + 0.408 + 0.473 = 6.606\ \mathrm{kN/m^2}$$
(3-4)
$$l_0 = \min\left\{ L_n + \dfrac{b_A + b_B}{2},\ 1.05 L_n \right\} = \min\left\{ 1.4 + 0.2,\ 1.05 \times 1.4 \right\} = 1.47\ \mathrm{m}$$
(3-5)

四、荷载组合

$$p_u = \gamma_G g_k + \gamma_Q q_k = 1.3 \times 6.606 + 1.5 \times 3.5 = 13.838\ \mathrm{kN/m^2}$$
(4-1)
$$p_{qp} = g_k + \psi_q q_k = 6.606 + 0.4 \times 3.5 = 8.006\ \mathrm{kN/m^2}$$
(4-2)

五、内力计算

$$M_A = -\dfrac{13.838 \times 1.47^2}{16} = -1.869\ \mathrm{kN \cdot m/m}$$

六、配筋计算

按单筋矩形截面（b = 1000 mm）计算，截面有效高度按选筋表最大直径取：

$$h_0 = t - c - d_{\max}/2 = 100 - 15 - 16/2 = 77\ \mathrm{mm}$$
(6-1)

最小配筋面积 $A_{s,\min} = \rho_{\min} b h = 0.2\% \times 1000 \times 100 = 200\ \mathrm{mm^2}$。

$$\alpha_s = \dfrac{1868847}{1 \times 14.3 \times 1000 \times 77^2} = 0.0220,\qquad \xi = 1 - \sqrt{1 - 2\alpha_s} = 0.0223$$
(6-2)

A端支座选用 $\Phi8@200$（$A_s = 251.3\ \mathrm{mm^2}$）。

—最小配筋 $A_s \ge \rho_{\min} b h$：251.3 ≥ 200 mm²，比值 0.7958 —— 满足
依据：GB/T 50010-2010（2024 年版）第 8.5.1 条

七、裂缝与挠度验算

按准永久组合并考虑长期作用影响，最大裂缝宽度限值 0.3 mm；跨中长期挠度限值 l₀/200。

$$\omega_{\max} = \alpha_{cr} \psi \dfrac{\sigma_s}{E_s}\left( 1.9 c_s + 0.08 \dfrac{d_{eq}}{\rho_{te}} \right) = 1.9 \times 0.200 \times \dfrac{97.7}{200000} \times \left( 1.9 \times 20 + 0.08 \times \dfrac{8}{0.0100} \right) = 0.019\ \mathrm{mm}$$
(7-1)
—跨中裂缝宽度 $\omega_{\max} \le [\omega] = 0.3$：0.01893 ≤ 0.3 mm，比值 0.0631 —— 满足
$$h_0' = h_0 + \lambda\, d\cos\alpha = 81 + 0.2 \times 150 \times 0.8815 = 107.4\ \mathrm{mm},\qquad f = \eta\, p_{qp} l_0^4 \times 10^{12} / B_l = 0.56\ \mathrm{mm}$$
(7-2)
—跨中挠度 $f \le [f] = l_0/200$：0.5578 ≤ 7.35 mm，比值 0.07589 —— 满足
依据：GB/T 50010-2010（2024 年版）第 7.1.2 条、第 7.2.2 条
